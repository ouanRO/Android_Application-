# Limoges Express Delivery

**Limoges Delivery App** is a native Android application designed to facilitate local delivery services within the city of Limoges and its surrounding areas. It connects local vendors, delivery drivers, and customers for efficient local logistics.

##  Features
*  **Order Placement:** Browse local products, add items to cart, and place delivery orders.
*  **Location & Tracking:** Geolocation integration to set delivery addresses within Limoges and track delivery status.
*  **Driver Interface / Routing:** View assigned delivery routes and manage order pickups and drop-offs.
*  **User Profiles:** Manage customer accounts, order history, and delivery preferences.

## Tech Stack
* **Platform:** Android
* **Language:** Java / Kotlin
* **IDE:** Android Studio
* **Libraries & Tools:** Android SDK, Google Maps API (or OpenStreetMap), Material Design components.
